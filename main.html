Desk Assistant Robot Arm

A standalone 4–5 DOF arm that hands you objects (starting with textbooks). Built from scratch — mechanics, electronics, and software.

Project Overview

Building a fully standalone desk assistant robot arm. Primary v1 goal: grab textbooks from the desk and hand them over. Every major component is designed and built in-house (no kits).

  • Degrees of freedom 4–5 DOF arm + parallel gripper
  • Servos MG996R ×5 (6 bought, 1 spare)
  • Servo specs 40.3 × 20 × 36.6 mm · 47.6 mm total · 9.4–11 kgf·cm
  • Material PETG (stronger & more heat-resistant than PLA)
  • CAD Onshape
  • Gripper Gear-driven parallel, two fingers, textbook-spine ready
  • Vision / Voice Full YOLO + full Whisper (no lightweight models)
  • Sim / RL MuJoCo (macOS) · PPO before real hardware
  • Laptop Mac

Architecture Decisions

  • Fully standalone — not tethered to the laptop.
  • Arduino Mega handles all servo PWM + sensor readings across every phase.
  • No Raspberry Pi 4 — dropped from the plan.
  • Pi 5 8GB runs full YOLO + OpenCV + full Whisper + decision logic and commands the Arduino over USB serial.
  • No PCA9685 — Mega has enough native PWM pins.
  • Power split: 5V 8A DC supply for servos; dedicated PSUs for Pi boards.
  • LCD shows arm status and voice commands.

Permanent microcontroller roles

Arduino Mega
Servo PWM control + all sensor readings (every phase)
Pi 5 8GB
Full YOLO + OpenCV (Phase 2+) · Full Whisper + decisions + Arduino commands (Phase 3+)
Jetson Nano
Advanced AI, 3D mapping, pattern learning (Phase 5+)

6-Phase Build Plan

Phase 1 — Basic Movement ~$112–142
  • Arduino Mega — servo PWM + LCD
  • MG996R ×6 — arm joints + gripper
  • I2C LCD, 5V 8A PSU, breadboard, jumpers, screws
  • HC-SR04 proximity (safety stop)
  • ACS712 ×6 current sensors (servo protection)
  • PETG structure on 3D printer
Phase 2 — Vision +$40
  • USB 1080P camera (with mic)
  • Micro USB OTG adapter for Pi 5
  • VL53L0X ToF sensor — exact distance before grip
Phase 3 — Voice Control +$190
  • Raspberry Pi 5 8GB
  • USB mic / camera mic + 3.5mm speaker
  • MicroSD, MPU6050 IMU, load cell + HX711
Phase 4 — Precision + Feedback +$50–80
  • Force sensors ×2 (one per finger)
  • Rotary encoders ×4 (base, shoulder, elbow, wrist pitch) for closed-loop control
Phase 5 — Full Autonomy +$250–350
  • Intel RealSense D435 + Nvidia Jetson Nano
  • Slip sensors ×2, LiPo pack, Arducam Module 3, USB audio adapter
  • 3D mapping, custom object recognition, gesture recognition
Phase 6 — Mobile Manipulator Future
  • Differential-drive wheel base (2 powered + 2 casters)
  • L298N motor driver, LiDAR, larger LiPo
  • Motorized docking platform at desk edge + magnetic lock
  • ROS2, SLAM, navigation stack
  • Advanced tasks: MacBook charging, drawer access, water bottle retrieval
